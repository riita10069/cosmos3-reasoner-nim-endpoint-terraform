# License and provenance of paper inputs

The 21 JSON files in this directory are the locked inputs used to generate the
paper. They contain no original videos, frame images, ROAD annotation files,
Oxford RobotCar sensor files, OPR source files, or OpenStreetMap snapshot.

They include deterministic clip-level benchmark and ground-truth metadata
derived from ROAD annotations, aggregate model-evaluation and serving
measurements, and derived motion or map-context summaries.
